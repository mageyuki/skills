# Security Policy

Skills are executable instructions: after discovery, they can direct an agent's tool use. Review skill content and registry changes before enabling them.

Report unsafe instructions, registry path traversal, cache escape, or other vulnerabilities through GitHub private vulnerability reporting for `mageyuki/skills`. Do not open a public issue for an undisclosed vulnerability.

Never include credentials, tokens, private keys, raw secret state, or other secrets in vulnerability reports. Minimize personal and tenant-specific data in every report and attachment.
